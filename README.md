# 全国「地方版みらい議会」リンク集・ポータル

全国の市民・シビックテック・有志が作成した「地方版みらい議会」や関連コンテンツ（Webアプリ、4コマ漫画、動画解説など）をつなぐ総合ポータルサイトです。

## 主な機能

1. **日本列島マップ ＆ 地域スライドタブ**
   - 日本地図のブロックから直感的に各エリア（九州・沖縄、近畿、関東など）を選んで絞り込み
   - スマートフォンでも親指でスイスイ切り替えられる横スライドタブバー
2. **キーワード・ジャンル・自治体区分検索**
   - 「大分」「世田谷」「マンガ」「AI」などの自由キーワードでリアルタイム検索
   - 都道府県・市区・町村などの自治体レベルでの絞り込み
3. **「作ったよ！」登録・報告フォーム**
   - 新たに地方版みらい議会や関連コンテンツを作った人が、サイト情報・工夫した点を申請できるフォーム（`/submit`）
4. **「となりの政治」との親和性**
   - 「日常と政治をつなぐ」をテーマにした温かみのあるデザイン
   - Google サイト「となりの政治」へのiframe埋め込みやリンク設置に最適化

## ローカル開発

```bash
# 依存関係のインストール
pnpm install

# 開発サーバー起動（ポート 3005）
pnpm dev
```

ブラウザで `http://localhost:3005` を開きます。

## Vercelへのデプロイ方法

1. GitHubに新しいリポジトリ（例: `mirai-gikai-portal`）を作成し、本フォルダのコードを push します。
2. Vercel ダッシュボードで「Add New...」→「Project」を選び、上記リポジトリをインポートします。
3. デフォルト設定のまま「Deploy」を押すだけで、数十秒で全世界に公開されます。

## Google サイト「となりの政治」への掲載方法

1. **埋め込み表示する場合**:
   - Google サイトの編集画面で、右パネルの「**挿入**」→「**埋め込み**」を選択
   - 「URL別」タブにデプロイされたVercelのURLを入力して「挿入」を押す
2. **リンクボタンとして置く場合**:
   - Google サイトの編集画面で「**ボタン**」を配置し、リンク先にVercelのURLを設定
